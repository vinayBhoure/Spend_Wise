# SpendWise - Free vs Plus Features

## 🆓 FREE PLAN
**Core expense tracking for everyone**

---

### ✅ Authentication & Onboarding
- Email/Password Sign Up & Sign In
- Google OAuth Sign In
- 1-Screen Onboarding Flow
- Currency Selection at Onboarding
- Account Creation Wizard

---

### ✅ Accounts (Limit: 3 accounts max)
- Account Types: Bank, Cash, UPI, Credit Card
- Add/Edit Account Details
- Live Account Balance
- **Single Currency per Account**

---

### ✅ Transactions (Limit: Last 6 months only)
- Add Income/Expense/Transfer
- Required Fields: Amount, Category, Account, Date
- Optional Fields: Note, Time
- Edit/Delete Transaction
- Transaction Detail View
- Optimistic UI Updates
- Transactions Grouped by Date

---

### ✅ Categories
- Default System Categories (Income + Expense)
- "Other" Catch-all Category
- ❌ **No custom categories** (use defaults only)

---

### ✅ Dashboard (Current month only)
- Total Balance (all accounts)
- This Month Income, Expense, Savings
- Last 10 Transactions Preview
- Category Pie Chart (current month)
- Empty State with CTA

---

### ✅ Filters (Basic)
- Quick Period Filters: Week/Month
- Type Toggle: All/Income/Expense/Transfer
- Single Category Filter
- Single Account Filter
- Include/Exclude Transfers Toggle

---

### ✅ Statistics (Limited)
- Basic Statistics (current month category breakdown)
- Category Pie Chart

---

### ✅ Settings
- Dark/Light Mode Toggle
- Currency Preference (locked after setup)
- Edit Profile (name, avatar)

---

### ✅ PWA
- PWA Installable
- Offline Support (IndexedDB cache)
- Background Sync

---
