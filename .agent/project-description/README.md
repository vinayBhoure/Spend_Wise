# Project Description: SpendWise

SpendWise is a premium, minimal, and habit-focused financial management app designed to help users track their spending with frictionless interactions and a sleek, dark-first aesthetic.

## Core Design Philosophy
- **Premium Dark Aesthetic:** Utilizing a deep navy and emerald color palette (#0A0F1E background with #00E6CB accents).
- **Frictionless UX:** Optimized for speed with clear typography, thumb-friendly targets, and minimal navigation depth.
- **Consistent Visual Language:** Unified iconography and typography across all functional modules.

## Key Functional Modules & Screens

### 1. Onboarding & Authentication
- **Onboarding (Refined):** High-impact introductory sequence setting the speed promise.
- **Auth (Refined):** A unified login/signup interface with email/password and social OAuth (Google/Apple) support.
- **OTP Verification (Refined):** Secure sign-up flow with segmented input fields and a countdown resend mechanism.
- **Account Creation (Refined):** A streamlined wizard for setting up initial financial accounts (Bank, Cash, UPI, Card).

### 2. Transaction Management
- **Add Transaction (Refined):** A 3-tap completion bottom-sheet with a prominent category emoji grid and time/date selectors.
- **Transactions List (Refined):** A date-grouped ledger with filters for time ranges and transaction types.
- **Edit Transaction:** A detailed form for modifying past entries, adding notes, or attaching chips-based labels.
- **Transfer Funds (Refined):** A dedicated flow for moving money between internal accounts with balance previews.

### 3. Insights & Statistics
- **Dashboard (Refined):** The central hub showing total balance, monthly income/expense summaries, and a habit streak tracker.
- **Statistics (Refined):** A category-based spending analysis using a donut chart and an account-wise spending breakdown.

### 4. Account & Profile Management
- **Accounts (Refined):** A vertical stack of account cards displaying total spent per account and balance visibility toggles.
- **Edit Account (Refined):** Management interface for archiving, deleting, or excluding accounts from the total balance.
- **Profile (Refined):** User settings hub for profile edits, plan management (Free/Pro), and account security.
- **Delete Confirmation (Refined):** A multi-step destructive action flow requiring email confirmation for safety.

### 5. Application Settings
- **Settings (Refined):** Centralized preferences including Currency selection, Dark Mode toggle, and Haptic Feedback controls.
